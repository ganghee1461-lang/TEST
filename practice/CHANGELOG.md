# 변경 이력

## 2026-11-17 — 웹앱으로 분리 (v1)

**웹앱**
- claude.ai 아티팩트 '가스기능사 실기 연습장'을 태블릿용 웹앱으로 옮김 (`practice/`).
- Claude 기능은 Anthropic API 키로 직접 호출. 스트리밍, 문제은행 조회 도구, 사진·손글씨 이미지 전송 지원.
- 풀이 기록·설정·Claude 대화를 기기 IndexedDB에 저장. 아티팩트의 풀이 기록(57개 세트, 872문제)을 첫 실행 때 자동으로 넣음.
- ⚙ 설정: API 키, 튜터 모델, 사용량(토큰·대략 금액), 백업 저장/불러오기, 데이터 새로 받기, 잠그기.
- 문제·사진 AES-GCM 암호화(PBKDF2 31만 회). 서비스 워커가 풀어서 보여 주고 오프라인 보관.
- 홈 화면에 추가(PWA) 가능.

**문제 추가**
- 작업형 2026년 1회(신출) 2문제: 매설배관 기초·침상재료와 두께, LPG 용기 재검사.
- 작업형 2026년 2회(신출) 5문제: 아세틸렌 충전구 형식, LPG 강제용기 내용적, 공기액화분리 원리, 고압·중압 배관 이격거리와 6m 도로 매설깊이, 저장탱크 충전 90%.
- 2026년 3회는 교재와 겹치지 않는 문제가 4번(영상 속 긴급차단 밸브 고르기) 하나뿐인데, 영상 없이 풀 수 없고 정답도 엇갈려 넣지 않음.
- 2026 경향 예상문제 12개(`x2026`, '예상 신출' 묶음): PE관 SDR 21·SDR 계산, 보호판 구멍 지름·두께, 방호구조물 이격, 반밀폐식 보일러 급기, 배류법 T/B, 삼각기 색, FID 명칭, RTU 목적, LPG 강제용기 범위, 매설배관 색.
- 출처: 수험생 복원 자료를 참고해 문장은 새로 씀. 근거가 불확실한 답(아세틸렌 B형, 재검사 4등급, D·E 층 구분)은 문제 화면에 '책 대조 필요'로 표시.
- 매설 단면도(`img/w2026-1-q02.png`)는 직접 그림. 나머지 2026 문제 사진은 교재의 같은 설비 사진을 씀.

**사진 정리**
- w2016 문제 50개의 사진이 JSON 안에 글자(base64)로 들어 있던 것을 파일로 뺌 (w2016.json 2MB → 50KB).
- 같은 사진이 여러 해에 반복된 것 146장을 72장으로 합침. 묶음마다 해상도가 가장 큰 것을 남김 (사진 489 → 343장, 14.2MB → 10.0MB).
- 빨간 동그라미·번호·Ex 표시처럼 **문제마다 표시가 다른 사진은 합치지 않음** ('지시하는 부분' 문제의 표시를 지키기 위해).
